Add a plugin system to the application.
plugins are extensions that can be installed and uninstalled.
They could be:
- UI components, that can be used in the baitler frontend
- API endpoints, that can be used by the ai
- mcp server extensions, that can be used by the ai

The llm models (claude code, minimax and future providers) should be able to create new plugins, install them and use them.

All this plugin system should be available through the mcp server.

Create a clear plan and strategy on how to implement this.
It should be a major feature of the platform. And will enable self-improvement of the platform.
